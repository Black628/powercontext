## 4. 检索质量（量化前后对比）

查询集（10 条，示例，可替换）：

1. 怎么在 AMD 平台上部署 seekdb
2. 全文索引用哪个分词器处理中文
3. 如何获取部署实例的遥测 ID
4. 向量检索和全文检索怎么融合
5. 为什么写入后马上查不到
6. INT8 和 FP16 怎么选
7. WebGPU 不可用会怎样
8. 增量导入后索引怎么刷新
9. seekdb 的最小资源要求
10. RRF 是什么

对同一查询集，用 FP32 与量化版本各跑一次，人工标注 Top-5 是否相关，计算：

- **Recall@5** = 命中相关文档的查询数 ÷ 查询总数
- **nDCG@5** = 按相关性分级（2=强相关，1=相关，0=不相关）计算

| 配置 | Recall@5 | nDCG@5 | 与基线差异 |
| --- | --- | --- | --- |
| FP32 基线 | | 1.00 | — |
| INT8（q8） | | | |
| FP16 | | | |

> 判定标准建议：量化后 Recall@5 下降 ≤ 0.1 视为"质量无明显下降"。
