### 2.2 输出与逐行对应

MiniMax 返回的修复（`evidence/minimax-raw-reply.md`）与最终 diff（`evidence/diff.patch`）一致：

```python
def shipping(amount_after_discount: Decimal, tier: str) -> Decimal:
    """Return the shipping fee for an order (S-04). ..."""
    if tier == "gold":
        return ZERO
    if amount_after_discount >= FREE_SHIPPING_THRESHOLD:
        return ZERO
    return SHIPPING_FEE
```

| diff 变化 | 对应规范 | 说明 |
| --- | --- | --- |
| 签名 `shipping(amount_before_discount, tier, amount_after_discount)` → `shipping(amount_after_discount, tier)` | S-04 | 判断基准改为折后金额，移除不再使用的折前参数 |
| 条件 `amount_before_discount > 99.00` → `amount_after_discount >= 99.00` | S-04 | 等于 99.00 也应包邮（原实现严格大于） |
| 新增 `if tier == "gold": return ZERO` | S-04 | 金卡会员始终免运费 |
| 调用点 `shipping(total, tier, after_discount)` → `shipping(after_discount, tier)` | S-05 | 同步调用点，返回字段不变 |
| docstring 由“折前金额 + 严格比较”改为“折后金额 + 至少 99.00 + 金卡” | S-04 | 文档与行为一致 |

MiniMax 的回复同时逐条核对了 3 个目标测试与 2 个相关回归测试的期望值（见原始回复），
并说明“原实现按折前金额且用严格大于比较，导致 99.00 整被收费、silver 折后 95.00 反而免运费”。

## 4. PowerContext 任务状态

### 4.1 接入方式

- 版本：PowerContext `1.4.1`，Server 由演示脚本以隔离目录启动：
  `POWERCONTEXT_HOME=run/powercontext`，`server run --no-env-file --port <空闲端口>`。
- Scope：`minimax-sdd-pricing`（`POST /v1/scopes` 幂等创建/复用）；
- 状态 Artifact：`family = atomic-memory`，`kind = sdd-task-state`，正文为 JSON（目标、状态、
  主条款、选中材料、已完成/待办、验证记录）。

> 兼容性说明：1.4.1 停用了旧版 Memory collection 读取接口（`GET .../artifacts/memory` 返回
> `422 legacy_memory_operation_unsupported`），因此使用官方推荐的 Atomic Memory 身份：
> `POST /v1/scopes/{id}/artifacts` 创建、`POST /v1/atomic-memory/list` 列表、
> `GET .../artifacts/atomic-memory/{id}` 读取、`PUT` + `If-Match` 追加修订。
