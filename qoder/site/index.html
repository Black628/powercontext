痛点

复习时最耗时的，不是学，是找。

课程笔记、论文 PDF、往期课件散落在不同地方。想不起关键词时，检索工具帮不上忙；找到了页面，也说不清哪一段支撑了哪个结论。

资料散落，想不起关键词

只记得“大概在哪一页”，却想不出原文用的词；纯关键词搜索一旦差一个字，就整页翻找。

检索靠运气

结论与原文脱节

读论文记不住哪段支撑了哪个结论，写综述时引用无法回溯到具体文档、页码与偏移。

出处不可追溯

错题反复错

没人记录“哪儿没懂”，每次复习都从零开始；薄弱知识点没有排序，时间总花在已经会的内容上。

记忆不复用

解决方案

双索引召回 + 出处引用 + 记忆复用

内容交给 seekdb，人物画像交给 PowerContext：一条链路完成导入、检索、问答与复习清单。

  1. 01

    导入与切块

    支持 .md / .txt / .pdf 文字层，按约 500 字切块，保留 doc_id、page 与 offset。

  2. 02

    建立双索引

    每块写入 seekdb：384 维向量列 + FULLTEXT ... WITH PARSER ik 中文全文索引。

  3. 03

    两路检索 + RRF

    向量近邻与 MATCH ... AGAINST 各自执行、各自计时，再用 RRF（k=60）融合排序。

  4. 04

    带出处回答与记忆

    top-k 片段进入问答，回答带 [n] 引用；薄弱点与问答历史写入 PowerContext。

不伪装成功：

PowerContext 未配置时，问答与检索照常返回，记忆读写降级为空操作。样例 3 因此如实标记为 FAIL，而不是改写成 PASS。

技术分工

seekdb 管内容，PowerContext 管人。

两个组件各自承担责任，也各自留下可核对的证据：SQL 原文、耗时、写入/读取日志。

seekdb

内容检索 · 向量 + 全文

已实测
  • 3 篇文档 / 9 块，导入总耗时 574.5 ms。
  • 样例 1：命中 2 个片段（offset 0 / 529），向量路 4.1 ms / 全文路 3.7 ms。
  • 样例 2：纯关键词 top-5 漏召回；目标块向量路 rank=6 被召回，RRF 融合后 rank=6；关键词 1.9 ms / 向量 1.4 ms / 全文 1.5 ms。
  • 两路 SQL 原文与各自耗时都打印到 INFO 日志，评审可直接复核。
建表与索引 · scripts/init_seekdb.sql
embedding    VECTOR(384)
FULLTEXT INDEX ft_content(content) WITH PARSER ik
VECTOR INDEX vidx(embedding)
  WITH (distance=cosine, type=hnsw, lib=vsag)

运行形态：v1.4.0.0 · WSL2 发行版 seekdb · 端口转发到 127.0.0.1:2881；embedding 为 hash，dim=384。

架构

一条查询，两条检索路径，一次融合。

浏览器只面对 FastAPI；FastAPI 分别执行向量路与全文路 SQL，候选结果经 RRF 融合后返回带出处的 top-k。记忆读写独立于检索链路，可降级。

核心功能

6 个接口，覆盖导入、检索、问答与复习。

接口定义见 app/main.py。未配置 LLM 网关时，/api/ask 退化为抽取式回答，仍然带 [n] 引用与出处。

POST/api/docs

上传 .md / .txt / .pdf，返回 doc_id，后台完成切块与双索引构建。

GET/api/docs

查看文档列表与索引状态，确认导入是否完成。

POST/api/search

输入 {query, k}，返回 top-k 片段、出处与两路各自得分，以及 RRF 融合分数。

POST/api/ask

输入 {query, uid?, topic?, understood?}，返回带 [n] 引用的回答与命中片段。

GET/api/review?uid=

今日复习清单，薄弱点次数来自 PowerContext 记忆；未配置时返回空清单。

GET/api/stats

导入量、检索次数与估算节省时间；为「使用效果」提供原始计数。

如何运行

三条命令，从导入到自检。

前置：seekdb 已启动并可在 127.0.0.1:2881 连接；PowerContext 可选。所有命令在 qoder/ 目录执行，配置参考 app/.env.example。

01

导入样例文档

首次运行会自动建库建表；可重复执行，脚本会先清理旧块。

python scripts/seed_docs.py
02

启动 API 服务

FastAPI 提供检索、问答、复习与统计接口。

uvicorn app.main:app --host 0.0.0.0 --port 8000
03

一键自检

打印 4 个样例的 PASS/FAIL、两路 SQL 与耗时；任一 FAIL 时退出码非 0。

python scripts/smoke_test.py
